Beispiel zur Berechnung des versteckten Selbstvertrauens (SV)

Im Aufstellungssimulator werden nur ganzzahlige SV-Werte zur Auswahl angezeigt. Intern arbeitet Hattrick jedoch mit genaueren Zwischenwerten. Diese können über die Änderung der Angriffsratings (AR) näherungsweise berechnet werden.

Beispiel

  • SV „gut“ = 6,5 → Angriff = 10,50
  • SV „ausgezeichnet“ = 7,5 → Angriff = 11,25

Der Unterschied von 1,0 SV-Punkt bewirkt also eine Änderung von 0,75 Angriff-Punkten.

Wird im Sandbox-Modus für die aktuelle Fähigkeitsstufe ein Angriffs-Wert von 10,75 angezeigt, ergibt sich:

1. Differenz berechnen

10,75 − 10,50 = 0,25

2. SV-Anteil per Dreisatz berechnen

SV-Anteil = 0,25 / 0,75 = 0,333

3. Anteil zur Ausgangs-SV addieren

6,5 + 0,333 = 6,83

Ergebnis

SV ≈ 6,83

Diese Berechnung basiert auf linearer Interpolation zwischen zwei bekannten SV-/Angriffs-Werten.


- kleine Rundungsabweichungen durch Hattricks internes Ratingsystem sind möglich.
- die Genauigkeit hängt stark von identischen Rahmenbedingungen ab. (gleiche Aufstellung, gleiche Form, gleiche Erfahrung usw.)
